# Install gws Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install the Google Workspace CLI (`gws`) declaratively through the existing NixOS flake and Home Manager setup.

**Architecture:** Add `googleworkspace/cli` as a flake input, expose its default package through the existing overlay, and include `gws` in the user's Home Manager `home.packages`. Do not install `google-cloud-sdk` in this change.

**Tech Stack:** Nix flakes, NixOS, Home Manager, upstream `github:googleworkspace/cli` flake.

### Task 1: Add the upstream gws flake input

**Files:**
- Modify: `/home/pexea12/nixos-config/flake.nix`

- [ ] **Step 1: Inspect current flake inputs**

Run:

```bash
cd /home/pexea12/nixos-config

```

Expected: command succeeds and shows existing `nixpkgs` and `home-manager` inputs.

- [ ] **Step 2: Add `googleworkspace-cli` to the inputs block**

Change the top of `/home/pexea12/nixos-config/flake.nix` from:

```nix
{
  description = "Nix Flake";
  inputs = {
    nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable";
    home-manager = {
      url = "github:nix-community/home-manager";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
```

to:

```nix
{
  description = "Nix Flake";
  inputs = {
    nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable";
    home-manager = {
      url = "github:nix-community/home-manager";
      inputs.nixpkgs.follows = "nixpkgs";
    };
    googleworkspace-cli = {
      url = "github:googleworkspace/cli";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
```

- [ ] **Step 3: Update the flake lock for the new input**

Run:


Expected: command succeeds and updates `/home/pexea12/nixos-config/flake.lock` with `googleworkspace-cli` and its non-followed inputs.

- [ ] **Step 4: Verify flake metadata includes the new input**

Run:

```bash

```

Expected: output includes a `googleworkspace-cli` input pointing to `github:googleworkspace/cli`.

- [ ] **Step 5: Commit the input addition**
